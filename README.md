This website is dedicated to the SCP universe. It contains information about certain secure-class objects, as well as those belonging to the Euclid and Keter classes. Here you can find data about competing organizations associated with the Foundation, including their composition and personnel. In addition, the website offers versions of the Foundation’s official and Russian websites, as well as information about some channels dedicated to this universe.

What is this created on?

This web resource was developed using HTML, CSS, and the Russian framework Photon — a lightweight, efficient, and modern tool for creating websites and landing pages.
